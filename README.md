# أنشودتي 🎤

مكتبة أناشيد للأطفال (٦–١٢ سنة) ينشدونها بأصواتهم: قصائد شوقي وحافظ والرصافي وأبي ماضي وأناشيد المناهج، مع معاني الكلمات بالصور، وحكايات مصوّرة، وحفظ متدرّج، واختبارات، وشارات تقدّم لكل طفل.

## التنزيل
من صفحة **[Releases](../../releases/latest)**:

| الجهاز | الملف | ملاحظة |
|---|---|---|
| أندرويد (هاتف/تابلت) | `Anasheed-*.apk` | اسمح بالتثبيت من مصادر غير معروفة. التحديثات تُثبَّت فوق القديم دون فقد التسجيلات. |
| ويندوز | `Anasheed-Setup-*.exe` أو `Anasheed-Portable-*.exe` | عند «Windows protected your PC»: More info ← Run anyway (البرنامج غير موقَّع تجارياً). |
| آيفون/آيباد | الرابط على GitHub Pages | افتحه في Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية». |
| معاينة | `Anasheed.html` | ملف واحد؛ التسجيل لا يعمل فيه على الهاتف. |

## ما في التطبيق
- **ملف لكل طفل** وشارات لكل نشيد: 👂 سمعتُه أو تابعتُه للآخر · 🎤 أنشدتُه · ⭐ نجحتُ في الاختبار · 🧠 حفظتُه غيباً.
- **الإنشاد بأربعة مستويات حفظ**: كامل ← نصف ← أوائل الكلمات ← غيباً (المس البيت لتلمحه).
- **النشيد الطويل يُقسَّم مقاطع** (٦ أبيات) ويتذكّر التطبيق أين توقّف الطفل.
- **نموذج الوالد**: سجّل النشيد بصوتك واختر «نموذج» فيظهر للطفل زر «اسمع النموذج».
- **ثلاثة اختبارات**: أكمل البيت · ما معنى الكلمة (بالصور حين تتوفر) · رتّب الأبيات.
- **قبل/بعد**: يسمع الطفل أول تسجيل له ثم آخره.
- **مشاركة التسجيل** إلى واتساب وغيره.
- **صفحة الوالد**: تقدّم كل طفل وعمره، إضافة أناشيد، نسخة احتياطية.
- **🦜 ردّد بعدي**: الوالد يسجّل النموذج ويضغط ⬇ مع كل بيت؛ فيسمع الطفل البيت ثم يأتي دوره ليردده. يناسب من لا يقرأ بعد.
- **مؤشر صوت** أثناء التسجيل، وتنبيه حين يكون الصوت خافتاً.
- **🎭 مسرح العائلة**: أبيات النشيد بأصوات الإخوة والوالد متتابعة، تُشارَك ملفاً واحداً.
- **🏅 شهادة حفظ** صورة تُحفظ وتُطبع حين يحفظ الطفل النشيد غيباً.
- **اختبار سهل** لمن عمره ٨ فأقل (خيارات بقوافٍ مختلفة، وصور أكثر).
- **💬 حديث مع والدك**: أسئلة حوار بعد كل حكاية (مسودة في `content/lessons.json` تحتاج مراجعة).
- **بطاقات بالصور** في الرئيسية، و🦜 على الأناشيد التي لها صوت الوالد بيتاً بيتاً.
- **الحكاية كتاب مصوّر كامل**: كل الأبيات تحت صورها، ولمس الصورة يُسمع أبياتها بصوت الوالد.
- **حاجز الوالد**: صفحة الوالد والحذف والاستيراد بضغطة مطوّلة ٣ ثوانٍ.
- **النسخة الاحتياطية** تحمل التسجيلات، وتنقسم ملفات إن كبرت؛ والاستيراد يدمج التقدّم ولا يمحو الأحدث. صفحة الوالد تذكّر بالتسجيلات التي ليست في أي نسخة.

## تعديل المحتوى
- النصوص: `content/texts.md` (كل بيت سطر: `الشطر الأول / الشطر الثاني`).
- المعاني: `content/glossary.py`.
- صور الكلمات والمشاهد: `content/images.json` و`content/story.json`.
- أسئلة الحوار: `content/lessons.json`.
- الواجهة: `src/template.html`.
- حكاية مصوّرة جديدة: `python3 scripts/add_story.py <رقم النشيد> صورة1 صورة2 صورة3 صورة4` (الأبيات من `docs/story_plan.json`، والبرومبتات في `docs/برومبتات_الحكايات_المتبقية.md`).

كل دفع إلى `main` يبني تلقائياً (GitHub Actions): يفحص النصوص، يشغّل اختباراً آلياً كاملاً في متصفح، ثم يبني APK ونسخة ويندوز وينشر صفحة الويب ويصدر Release.

البناء المحلي: `python3 build.py` ← `www/index.html` و`dist/أنشودتي.html`.

## حقوق النصوص
لا يدخل التطبيقَ إلا ما نُشر قبل ١٩٢٩ لشعراء متوفَّين. النصوص المحمية (موطني، سليمان العيسى، …) يضيفها الوالد من صفحة الوالد لاستعمال أسرته.
